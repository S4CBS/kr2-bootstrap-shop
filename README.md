## 1. Краткое описание проекта
KeyCraft — современный веб-интерфейс интернет-магазина кастомных механических клавиатур, переключателей и аксессуаров. Проект выполнен на базе CSS-фреймворка **Bootstrap 5 (v5.3.3)** с сохранением предметной области первой контрольной работы, но с нуля спроектирован по канонам компонентной модели и адаптивной сетки Bootstrap.

Все страницы адаптированы для мобильных устройств, планшетов и широкоформатных экранов, используют семантическую разметку, доступные интерактивные компоненты (модальные окна, аккордеоны, вкладки, слайдер, всплывающие уведомления) и расширенную форму заказа с валидацией.

## 2. Используемый фреймворк и способ подключения

### Используемый фреймворк
**Bootstrap 5.3.3** (полнофункциональный релиз со встроенным Popper.js в bundle).

### Способ подключения
В проекте выполнено **локальное подключение** Bootstrap (без зависимости от внешних CDN), что обеспечивает автономность работы сайта и стабильную загрузку даже без подключения к интернету.

Файлы фреймворка размещены в папке `vendor/bootstrap/`:
- `vendor/bootstrap/css/bootstrap.min.css` — скомпилированные стили фреймворка;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript-бандл (включает логику Dropdown, Collapse, Modal, Tab, Carousel, Toast).

### Порядок подключения стилей
Пользовательский файл `css/custom.css` подключается строго **после** Bootstrap CSS:
```html
<!-- 1. Библиотека Bootstrap -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<!-- 2. Пользовательские точечные переопределения -->
<link rel="stylesheet" href="css/custom.css">
```
Это гарантирует, что каскад стилей (CSS Cascade) позволяет точечно настраивать фирменную палитру, hover-эффекты и декоративные элементы без нарушения сетки фреймворка.

## 7. Ответы на контрольные вопросы по КР №2

### 1. Что такое CSS-фреймворк?
**Ответ:** CSS-фреймворк — это готовая библиотека преднастроенных стилей, адаптивных сеток, утилитных классов и готовых UI-компонентов (кнопки, формы, навигация, карточки, модальные окна), ускоряющая разработку кроссбраузерных и адаптивных веб-интерфейсов за счет стандартизированной структуры кода.

### 2. Почему Bootstrap выбран как основной вариант?
**Ответ:** Bootstrap — самый зрелый, документированный и стабильный CSS-фреймворк с мощной 12-колоночной сеткой на Flexbox, богатым набором интерактивных JS-компонентов, поддержкой доступности (ARIA) и широким признанием в промышленной разработке.

### 3. Какие альтернативные CSS-фреймворки допускаются?
**Ответ:** Согласно методическим указаниям, допускаются утилитарный фреймворк **Tailwind CSS** и легковесный компонентный фреймворк **Bulma** (при условии реализации всех требований к сетке, компонентам и формам).

### 4. Для чего используется `container`?
**Ответ:** Класс `.container` центрирует содержимое по горизонтали, задает адаптивную максимальную ширину (`max-width`) под текущую контрольную точку (breakpoint) и добавляет базовые внутренние боковые отступы (padding), предотвращая прилипание контента к краям экрана. Существует также `.container-fluid` для растягивания на 100% ширины.

### 5. Для чего используется `row`?
**Ответ:** Класс `.row` является непосредственным flex-контейнером для колонок `.col-*`. Он компенсирует внутренние отступы колонок с помощью отрицательных внешних отступов (`margin-left` и `margin-right`) и управляет горизонтальным расположением элементов.

### 6. Для чего используются `col-*`?
**Ответ:** Классы семейства `.col-*` (например, `col-12`, `col-md-6`, `col-lg-4`) задают ширину колонки в долях от 12-колоночной сетки на соответствующих экранах, определяя правила адаптивного перестроения блоков от мобильных устройств до десктопов.

### 7. Что такое 12-колоночная сетка Bootstrap?
**Ответ:** Это система верстки, в которой ширина строки (`row`) условно разделена на 12 равных долей. Любой дочерний элемент может занимать от 1 до 12 колонок. Если суммарная ширина колонок превышает 12, лишние колонки автоматически переносятся на новую строку.

### 8. Для чего используются `g-*`, `gx-*`, `gy-*`?
**Ответ:** Это утилиты управления межколоночными интервалами (gutters):
- `g-*` задает одновременно горизонтальные и вертикальные отступы между колонками строки;
- `gx-*` управляет только горизонтальными отступами (по оси X);
- `gy-*` управляет только вертикальными отступами между рядами колонок (по оси Y).

### 9. Для чего используется `navbar`?
**Ответ:** Компонент `.navbar` предназначен для построения отзывчивой шапки сайта. Он включает в себя логотип бренда, навигационные ссылки, формы поиска, кнопки действий и автоматически поддерживает сворачивание навигации в мобильное гамбургер-меню через компонент Collapse.

### 10. Почему для мобильного меню нужен Bootstrap JS Bundle?
**Ответ:** Раскрытие и закрытие мобильного гамбургер-меню происходит динамически при клике на `.navbar-toggler`. Скрипт `bootstrap.bundle.min.js` слушает события клика, переключает CSS-классы анимации (`show`, `collapsing`), управляет атрибутом `aria-expanded` для скринридеров и рассчитывает высоту блока.

### 11. Для чего используется `card`?
**Ответ:** Компонент `.card` — гибкий структурированный контейнер контента с рамкой, скруглением и внутренними отступами. Он поддерживает логические зоны: `card-header`, `card-body`, `card-footer`, изображения `card-img-top` и идеально подходит для карточек товаров, отзывов и информационных блоков.

### 12. Для чего используется `badge`?
**Ответ:** Компонент `.badge` используется для вывода компактных меток, индикаторов статуса, счетчиков или акцентов (например, «Хит продаж», «Новинка», «Скидка -15%», количество товаров в корзине).

### 13. Для чего используется `alert`?
**Ответ:** Компонент `.alert` выводит важные контекстные сообщения и системные уведомления для пользователя (об успехе, ошибке, предупреждении или акции), часто комплектуется кнопкой закрытия `.btn-close` с атрибутом `data-bs-dismiss="alert"`.

### 14. Для чего используется `modal`?
**Ответ:** Компонент `.modal` выводит диалоговое окно поверх основного интерфейса с затемнением фоновой страницы (backdrop). Он блокирует взаимодействие с остальной страницей и фокусирует внимание пользователя на конкретной задаче (быстрый заказ, подтверждение действия, форма обратной связи).

### 15. Какие атрибуты нужны для открытия модального окна?
**Ответ:** Для открытия окна по клику на кнопку/ссылку без написания дополнительного JS используются data-атрибуты HTML5:
1. `data-bs-toggle="modal"` — сообщает Bootstrap, что элемент является триггером модального окна;
2. `data-bs-target="#idОкна"` — указывает CSS-селектор целевого модального окна (для тега `<a>` может использоваться `href="#idОкна"`).

### 16. Для чего используются `form-control`, `form-select`, `input-group`, `form-check`?
**Ответ:** Это классы стилизации элементов форм:
- `.form-control` — оформляет текстовые поля ввода (`<input>`, `<textarea>`);
- `.form-select` — оформляет выпадающие списки `<select>` с кастомной стрелкой;
- `.input-group` — объединяет текстовые поля с текстовыми префиксами/суффиксами или кнопками в одну непрерывную строку;
- `.form-check` — оформляет чекбоксы и радиокнопки с выравниванием метки `<label class="form-check-label">`.

### 17. Чем CDN-подключение отличается от локального подключения Bootstrap?
**Ответ:** При CDN файлы загружаются с удаленного распределенного сервера (например, jsDelivr) через интернет. При локальном подключении скомпилированные файлы фреймворка физически лежат внутри репозитория проекта в папке `vendor/`. Локальное подключение работает офлайн, независимо от внешних блокировок и изменений на сторонних CDN-серверах.

### 18. Какие файлы нужны для локального подключения Bootstrap?
**Ответ:** Минимально необходимый комплект compiled-версии:
1. `bootstrap.min.css` — таблица стилей всех компонентов и утилит;
2. `bootstrap.bundle.min.js` — JavaScript-движок фреймворка со встроенной библиотекой позиционирования Popper.js.

### 19. Почему `custom.css` должен подключаться после Bootstrap?
**Ответ:** В каскадной модели CSS правила, объявленные ниже в коде при одинаковом весе селектора, имеют приоритет. Подключение `custom.css` после `bootstrap.min.css` позволяет разработчику переопределять стили фреймворка своими селекторами без необходимости использовать антипаттерн `!important`.

### 20. Какие самостоятельные доработки были добавлены в проект?
**Ответ:**
1. Выполнено автономное локальное подключение Bootstrap в каталог `vendor/bootstrap/`;
